## Detailed description (dashboard)

```
Redirect and rewrite HTTP request URLs with regex rules — before the request leaves your browser.

Point a production API at localhost. Send CDN assets to a staging bucket. Swap a version number in
a script URL. Rewrite a query string. You write a regex for the URL you want to catch and a
replacement for what it should become, and every matching request goes to the new address instead.

WHAT IT DOES

• Redirect any request URL to another URL
• Match with full regular expressions, including capture group references ($1, $2, …)
• Turn each rule on or off individually, without deleting it
• Name your rules so a long list stays readable
• Copy an existing rule into the editor to make a variant in one click
• Export and import your whole rule list as JSON — move it between machines or share it with a
  teammate
• Badge on the toolbar icon shows how many rules are currently active, so you never forget a
  redirect is running

WHO IT IS FOR

Front-end and full-stack developers who need to test against a different backend without touching
the application code. QA engineers pointing a build at a test environment. Anyone debugging a
third-party script they cannot edit.

HOW IT WORKS

Built on Manifest V3 and Chrome's declarativeNetRequest API. Rules are compiled into native
browser redirect rules — the extension never reads your request bodies, never proxies your
traffic, and never sends anything to a server. There is no account, no sign-in, and no telemetry.
Your rules live in your browser's IndexedDB and nowhere else.

FREE

The URL-redirect feature that paid HTTP interceptors charge a monthly fee for, at no cost. No
trial, no seat limits, no upsell.

LANGUAGES

English, Korean, French, Spanish, Arabic, Russian, Chinese (Simplified). The interface follows
your Chrome language automatically.

OPEN SOURCE

https://github.com/YoungjuneKwon/just-replace-http
```
